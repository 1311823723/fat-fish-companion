| 仓库 | 所有权 |
| --- | --- |
| [fat-fish-cottage](https://github.com/1311823723/fat-fish-cottage) | 游戏前端、生活数据库、库存、衣柜、天气、旅行、照片、背包、收藏和小游戏 |
| [fat-fish-companion](https://github.com/1311823723/fat-fish-companion) | QQ/DSH、角色、身份验证、聊天记忆、日记原文、消息白名单与发送队列 |

## 当前边界

小屋是生活事实的唯一来源，桥接通过 `/internal/*` v1 读取和修改状态；QQ 不凭聊天描述自行认定出门、回来或吃过饭。发送前仍由桥接检查白名单、忙碌和发送预留记录。小屋通过聊天网关获取身份、网页聊天和日记，不读取桥接数据库或登录文件。照片分享通过带凭据的内部接口获取图片，不需要两边共享照片目录。

日记当前仍由聊天侧生成和保存，网页通过网关翻阅；本轮不搬动私人日记、角色卡和身份映射。旅行事件、照片和收藏由小屋保存。之后若迁移日记存储，应另做数据迁移和兼容接口，不能两边各写一份。

本版支持同一台电脑、两个任意位置的独立目录，不要求相邻或嵌套。内部接口仅允许本机环回地址。**分仓不等于跨机器部署**；当前并未实现远程核心、独立身份服务或跨主机密钥分发。聊天适配与生成式旅行目前仍需要 QQ 桥接提供文本模型，纯本地玩法不需要。

## 新安装（以下命令在小屋仓库中执行）

先在小屋仓库根目录按 README 跑通基础玩法。需要 QQ 时，在另一个目录安装聊天桥接，按它的 DSH-INSTALL.md 配置模型与 QQ。不要把聊天仓库克隆到小屋里面。

在小屋目录运行（把路径换成聊天桥接目录）：

```powershell
npm run bridge:link -- --bridge D:\Projects\fat-fish-companion
```

以上只预览。会话空闲并停止桥接、网关和小屋后，加 `--apply` 才写入：

```powershell
npm run bridge:link -- --bridge D:\Projects\fat-fish-companion --apply
```

脚本验证源码兼容性，备份将修改的文件，安装对应版本的适配器，配置两端链接；凭据不输出、不入库。保留已有端口、天气、绘图及存档；已有密钥冲突或部分接入时停止。它不安装 QQ 网关、不登录账号、不启动或终止任何服务，不自动迁移旧库存。首次迁移旧房间须先按 MIGRATION.md 核对并导入。

启动小屋、聊天桥接及原小屋网关后，运行两个仓库各自的诊断。在同一网址核对库存与在家/外出状态，完成真实 QQ 验证后再启用自主活动。链接文件为聊天目录下 `state/game-core-link.json`；小屋本机配置为 `config.local.json`。原 `photoDirectory` 仅为旧适配器回滚保留，新链接不再生成它。

## 分开升级与协议

- 小屋 `GET /health` 声明 `protocol: {name: "fatfish-life", version: 1}`；受保护快照声明 `protocolVersion: 1`，与 SQLite 的 schema 版本分开。
- 老版未声明协议的核心按 v1 兼容；明确声明不支持的版本时适配器拒绝，不推测状态。
- `adapters/` 是小屋发布的连接包；桥接 `src/game-*.mjs` 为安装副本。只通过明确的升级命令更新，不在启动时联网下载或覆盖代码。只改前端或兼容的生活规则无需重新复制适配器。
- 更新涉及连接包时，先备份，再预览并执行上面的连接命令；在空闲时重启两端。小屋根目录运行 `npm test`、`npm run build`、`npm run doctor`；聊天侧运行对应诊断。
- 备份位于小屋 `state/backups/bridge-link-*`，其中 `restore.json` 记录原文件位置。回滚须停相关服务，按清单恢复原文件；原先不存在的文件按清单移除。备份包含本机秘密，只留本机。

## 从旧单仓安装升级

已经运行的小屋和聊天目录不必移动、重新绑定或重新迁移存档。新仓库只是源码维护入口；先备份配置和状态，确认版本后更新对应目录。不要把新克隆目录空的 state 覆盖到正在使用的存档。

旧主仓库的 `archive/monorepo-20261112` 分支保留拆分前代码，只供回退，不继续合并新功能。主分支不再包含 game。历史没有重写，因此完整克隆旧主仓库仍可能带上旧素材；新部署可使用 `git clone --depth 1`。两边都不要再次启动旧生活调度器。

公网仍可选。只用本机或局域网不需要 Cloudflare；需要公网才按 DEPLOYMENT.md 配置。公开入口只转发小屋允许的接口，不能公开内部生活接口、桥接管理控制台、DSH 或 QQ 网关。
