# 记忆、日记与持续状态（2026-10-17）

## 行为

- `qq_memory_revise` 按会话、QQ号和稳定主题slot保存信息。事实fact须有当事人自己的来源消息；temporary默认7天，inference默认14天，fact默认365天。推测不能覆盖明确事实，旧消息不能覆盖新依据。
- 同一主题更新保留最近3次历史，但自动提示词只显示当前值。90天未更新的事实标记stale，提醒先确认。到期记录不再注入，不等于从磁盘物理删除。
- `supersedes` 可指定被替代的旧人账原句。这些句子在当前会话的提示词中隐藏；原账本仍在，便于回滚。旧事实没有来源元数据，不自动猜测迁移，需在实际聊天中逐步修正。`forget` 是停止注入该主题，不是安全擦除存档。
- `qq_diary_write/read` 改走桥接，要求key与会话token。新日记记录来源会话和可选消息ID；未标记场合的旧日记默认仅主人私聊可见。
- 每次唤醒/查询prompt时按最近真实消息找最多2条相关日记，减少无关往事注入。也可用read的query主动查；这是轻量文字相关性匹配，不是向量检索，可能漏掉同义表达。日记仍由她自愿写，每天全局最多3条，不设固定时间。
- `qq_self_state_update` 保存本会话的心情、精力、最多3个兴趣和2件惦记的事。更新须关联真实互动，至少间隔10分钟，精力一次最多变15。
- 心情12小时后回平常，精力逐渐向50回落；兴趣14天、惦记的事3天过期。相同条目重存不自动续期。状态按会话保存，避免私聊内容随状态泄入群聊；不是跨所有群共享的一份情绪。
- 不预写日记、兴趣或人格台词，不把没有实际执行的吃饭、刷视频等写成真实经历；状态不能作为不回应明确@或私聊的借口。
