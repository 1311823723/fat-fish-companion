# 主动联系的具体缘由

主动机会、独处时刻和待续话题唤醒会获得 initiative 候选；qq_get_prompt 也返回相同上下文。

来源：
- 当前会话真实收到的消息，以及仍有效、已到期的 pendingThought。
- 最近48小时真正打开并读到文字的公开内容，且与已保存的公开兴趣相关。

浏览保存 receipts；搜索结果/列表里的链接只算发现，不算打开过正文。B站页面只证明读取标题简介，不证明观看视频。旧浏览列表不补造成阅读经历。

过滤：已分享、分享冷却、过期内容、缺失来源消息、历史补课消息。主人浏览只用于主人私聊，不进入群聊。没有具体缘由时可以先浏览一到两页、写私人日记或安静；不再用无关热点填空。

本次沿用已有工具权限：公开页面浏览、日记、记忆、状态、现有白名单私聊分享。未增加网站域名、收件人或分享额度。QQ空间读写本来已开放，本次不扩大账号权限。

仍受既有20页/日、主人分享2条/24小时与6小时间隔，以及未回应后降频的限制。

验证：test-initiative-reasons.mjs（来源、实际打开、重复、冷却、过期、群私聊隔离、真实桥接唤醒和接口）；test-interest-care-api.mjs；test-interest-care.mjs。
