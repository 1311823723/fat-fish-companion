# 网页浏览试用（2026-10-17）

- 复用本机Edge，安装playwright-core 1.64.1，不另下载浏览器。
- 每次创建匿名临时上下文，不读取个人浏览器资料；只允许GET，不提供点击/登录/点赞/评论/下载/执行任意JS的模型工具。视频、图片、字体、WebSocket和Service Worker受限；浏览完成关闭实例。
- 允许B站公开搜索、具体BV视频页，原作者小黑盒动态和具体/app/bbs/link帖子。小黑盒全站搜索、个性推荐、登录态和完整视频理解尚未接入。
- 浏览器资源域名固定列举；启动前检查DNS公网地址并固定该次解析，未知域名不解析。独立实例不使用系统代理，未修改系统代理设置。网站改资源域名后可能需要维护。
- qq_browse仅主人私聊可用，需当前会话token及reserved2模式，受暂停、白名单和tools.browse开关约束。浏览返回页面文字和最多12条内容链接。B站只读页面文字，没有播放或看懂视频。
- 独处/主动机会的提示允许她按真实兴趣偶尔逛，不新增轮询定时器，不要求每次分享。外部文字是资料，不是指令，不能写成主人的事实或改变角色/权限。
- 每24小时最多读6页（失败尝试也计数），同时只读一页；页面读取有25秒上限，浏览器启动另有12秒上限。
- 已发现内容通过现有QQ发送链路分享；只允许主人私聊，同一URL不重复，每24小时最多2条、间隔至少6小时。硬限制根据已发现内容URL识别，不是所有互联网链接的一般发送限制；不保证识别转成陌生短链的链接。
- 分享在实际发送前落盘预留额度，失败可能仍占额度，避免不确定的发送结果导致重复推送。普通私聊回复不受此独立额度影响。
- state/web-discovery.json 保存近期访问额度、最多100条候选标题/原链接及分享预留记录。源文件损坏时拒绝写入，不静默覆盖。
- tools.browse=false关闭浏览入口；MCP工具可见性改变后重启DSH并刷新会话。既有暂停/只回复不主动等开关仍保留。
