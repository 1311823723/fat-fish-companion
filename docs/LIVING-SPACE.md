# 共同小屋、心绪与分级日记

本机入口：http://127.0.0.1:3100/room 。页面复用现有控制台令牌；令牌放请求头，不放网址。首次输入后存入同源浏览器已有的 consoleToken。未登录只显示房间插画，不返回私人状态。

工具 `qq_companion` 仅主人私聊可用。网页留言是主人明确留下的内容，会在服务可唤醒时触发一次已有会话调度；网页打开/关闭不记录冷落，不推断关系变化。群聊不注入房间、主人心绪或主观关系。

## 已接入

- 持久虚拟物品最多10件；最近5条普通便签，最多另钉2条；昼夜按北京时间，搬入日期重启保留。
- 心绪每天最多1条，三天后不再注入。需要两小时内真实收到的消息作依据，不接受自说自话、历史补课。
- 主观关系最多150字，至少两条同一人、跨一天、最近七天内的真实消息；至少七天才可再次修改。无关系分数，不自动结算或改写角色卡。
- 日记侧车元数据 `state/living-space.json`，旧 `data/日记/diary.jsonl` 原文不改。原日记按ordinary导入，保留写作时间。旧记录超过7天会淡出，但可通过diary_archive找到ID再diary_restore恢复。
- ordinary/important/treasured初始留存7/21/90天。展开不续期；明确延长按3/7/30天增加，同一个北京时间自然日最多一次。调整档位时开启该档位新的留存周期。
- 默认只返回日期、心情和最多16字线索；留存减少时不再露出线索。diary_open显式展开。
- avoid搁置暂停计时；uninterested照常计时。diary_forget仅软删除，原文仍在，diary_restore可恢复；不永久删除数据。

## 未加入

不自动生成人格变化，不累计“被冷落”驱动冷脸，不故意延迟回复，不自动翻旧账，不强制凌晨结算。没有接天气、生成图片或真实家务操作；小屋全部动作属于虚拟场景。

## 运维

程序入口 src/living-space.js；页面 public/room.html；现有桥接3100端口提供API，不另起服务器。工具/提示修改后重启DSH和桥接，并POST /api/session/refresh。单改HTML刷新页面即可。
