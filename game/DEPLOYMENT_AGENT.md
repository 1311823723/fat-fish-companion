# 给部署助手

目标：在用户自己的机器部署独立小屋，可选择本地、局域网或公网，之后再接入 QQ 和 AI。先阅读 README 和 docs 中的三份说明，不要求用户购买域名。

1. 检查 Node 24、可用端口和目录权限。使用独立目录，不覆盖现有机器人。
2. `npm ci`、`npm run setup`、`npm test`、`npm run build`、`npm run doctor`。配置只保存在本机；不打印真实凭据。
3. 首先验证纯本地游戏。没有模型时保持在家，不编造旅行；没有 QQ 时不要承诺分享成功。
4. 用户要迁移旧版时先只读核对计数，再按 MIGRATION.md 停旧写入、备份、导入和验证。用 stage-bridge 检查锚点，不能整包覆盖。
5. 私网按用户选择配置网关和可信来源；公网可用现有隧道，或按 DEPLOYMENT.md 使用 Cloudflare。登录、扫码和 OAuth 由用户完成。不要求用户把密码或令牌贴到对话。
6. 验证手机尺寸、实际交互、断线重连和公开接口边界；只有真实部署成功并能访问时才提供公网地址。
7. 发布使用 export.mjs 文件白名单并检查扫描结果，禁止上传状态、身份、聊天、日记、照片原件、日志、模型、备份和浏览器目录。代码与素材分别遵守许可证。

报告实际完成的工作、测试证据和阻碍。不要把准备好的配置或部署脚本当成已经发布。
