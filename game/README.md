# 大肥鱼的小屋

手机优先的陪伴生活小游戏。Phaser 4.2.1 绘制角色和房间，Node.js 24 + SQLite 保存唯一生活状态。QQ 和网页可使用同一份经历；聊天记忆仍按已验证 QQ 号关联，访客不能查看其他人的资料。

## 本地安装

安装 **64 位 Node.js 24** 和 Git。首次从仓库下载时，先进入 `game` 子目录；仓库根目录是旧版桥接，不能混用两套安装命令：

```powershell
git clone <仓库地址> fat-fish-companion
cd fat-fish-companion/game
npm ci
npm run setup -- --defaults
npm test
npm run build
npm run core
```

打开 `http://127.0.0.1:3103/room`。不配置 AI 和 QQ 也能补货、互动、准备背包和游玩；自主出游需要可用的意愿模型。配置保存在 `config.local.json`，存档、照片和备份在 `state/`，两者都不能提交 GitHub。

`<仓库地址>` 替换成当前仓库的克隆地址，不要原样执行尖括号。已下载 ZIP 时，解压后直接进入 `game` 再从 `npm ci` 开始。运行终端需要保持开启；关闭终端或电脑关机后，本机服务会停止。另开终端在同一目录运行 `npm run doctor` 检查启动状态。

基础安装不需要下载语音模型、模拟器或旧机器上的素材，授权素材已包含在仓库。`setup --defaults` 会关闭天气、QQ 和绘图并生成本机随机凭据；已有配置不会覆盖。首次想交互选择天气可用 `npm run setup`，已初始化后直接编辑本机配置，不删除正在使用的配置重新生成密钥。

端口被占用时不要停止不认识的程序。在本机配置中同时修改 `port` 和 `allowedOrigins` 中对应的本机地址，再用新端口访问；Vite 开发代理也需随之修改。诊断中的 `core:false` 在未启动时正常，启动后应为 `true`；端口上有其他 HTTP 服务时会报告 `portConflict`。

## 分阶段接入

| 能力 | 基础版是否可用 | 额外前提 |
| --- | --- | --- |
| 房间、窗帘、灯、冰箱、放食物、饱食、精力、背包 | 是 | 只需本机核心，默认不开天气 |
| 四子棋、棋谱、对战记录 | 是 | 不调用大模型；公开记录不显示 QQ 号 |
| 自动出游、路上表达、旅行纪念品 | 否 | 已接入的 QQ 桥接与可用文本模型，且自主活动已启用；无有效意愿就留家 |
| 新旅行照片 | 否 | 先完成出游接入，再配置绘图插件、固定参考图及本人登录；生成耗时和额度由上游决定 |
| 网页 AI 聊天、模型赛后复盘 | 否 | 文本模型和 QQ 桥接适配；复盘排队处理 |
| 房间快捷聊天、外出留言与可选 QQ 提醒 | 否 | 留言在本机持久化，回家后处理；提醒需 QQ 验证、主动勾选及私聊白名单 |
| QQ 联系、验证 QQ、跨入口个人记忆、主人日记 | 否 | 机器人账号、QQ 网关、桥接/DSH、白名单与主人身份配置；不是只填写 QQ 号就能开通 |
| 公网地址 | 否 | 本机后台持续运行，再选择隧道或 Cloudflare；静态托管不能代替后台 |

建议顺序：先验证纯本地玩法 → 按 [桥接说明](docs/BRIDGE.md) 接文本 AI/QQ → 按 [绘图说明](docs/AI.md) 开照片 → 最后按 [部署说明](docs/DEPLOYMENT.md) 开公网。源码随附的诊断和检查清单见 [首版发布验证](docs/RELEASE_READINESS.md)。不要把某一套已有环境的成功当成所有平台都已验证。

纯本地访客凭据有效期为 30 天，同一浏览器在重启核心后仍可找回自己的对战记录。退出登录、清理 Cookie、凭据过期或换浏览器后不能冒认旧访客。QQ 接入使用原网关的身份机制，已验证 QQ 可按号关联，权限不由显示昵称决定。

开发界面：`npm run dev`，默认 `http://127.0.0.1:5174`。诊断：`npm run doctor`。测试：`npm test`。构建：`npm run build`。

## 从旧版小屋迁移

先看 [迁移与回滚](docs/MIGRATION.md)。不要一边运行旧生活调度器，一边迁移生产存档。

```powershell
npm run migrate -- --source D:\Projects\qq-bridge
```

默认只输出计数，不写存档。`--apply` 才会生成数据库、备份旧房间存档并复制已公开的旅行图片。原身份映射、日记和聊天留在原项目，不进入发布包。任何未知库存或缺失照片都会阻止切换。

QQ 接入说明见 [兼容适配](docs/BRIDGE.md)，公网与私网说明见 [部署](docs/DEPLOYMENT.md)。将本仓库地址交给 DSH 或其他编程助手时，可让它按这三份文档先检查、再部署；账号登录和外部授权由部署者完成。

绘图接入见 [AI 与绘图](docs/AI.md)。模型或图片服务不可用时，保持在家或保留照片任务，不以随机行程和假图片兜底。

## 玩法

- 同一个 QQ 大肥鱼：网页与 QQ 共用饱食、精力、活动、库存、旅行与照片；个人记忆按已验证 QQ 关联。公网可选，本地核心配好 QQ/DSH 也能联动。
- 原有动作保留，新增坐着翻书、无声哼歌与端碗吃米饭；点击肥鱼还可能摸头回应或站着转一圈。反应有共享冷却，不打断睡觉、吃饭和出门，也不改变长期心情。
- 墙上电视：四子棋，默认普通局；多人独立对局、可回看的棋谱、公开对战记录与保存的模型复盘。规则、身份和升级见 [电视小游戏](docs/ARCADE.md)。
- 冰箱总共 12 份。16 款菜品每日提供 4 道主食、2 款饮品或汤，按北京时间轮换；旧库存保留。背包 9 种小物每日轮换，仍最多随身带三件。详见 [每日生活](docs/DAILY_LIFE.md)。
- 饱食每小时下降 3；低于 35 时，有库存会自动进食。离线最多温和结算 8 小时，不死亡、不扣关系。
- 背包最多三件，近处可不带饭，远行需要便当。没有明确自主意愿就留家。
- 回家按时间即时结算，照片任务失败不会让角色卡在外面。拍照记录冻结时间、天气、动作和参考版本，重试沿用。
- 分享只经 QQ 适配器当前白名单。发送前持久化预留；结果不明不重复发送。睡觉不会阻止正常回复私聊或艾特。

## 隐私与授权

匿名公开状态不包含天气坐标、QQ 号、补货者身份明细、聊天、日记或凭据。访客可自填 QQ 登记来访，该号码不证明身份；关联私人记忆或订阅 QQ 提醒必须通过机器人验证。来访明细和日记仅已验证主人可查看。留言按当前身份隔离，未确认的发送不会自动重复；服务重启后可在“我的留言”查看状态。来访按北京时间记录，短时间刷新去重，不会补造上线前的记录。部署者应自行备份本机数据库及密钥；更换加密凭据会使尚未处理的加密留言无法解密。

房间纪念角展示近期纪念品及同次旅行的照片；自动用餐从库存扣除，记录真实使用的食物。只有存货来源经过 QQ 验证时才关联放食物的人，迁移前的存货视为来源未知。自动选餐根据实际用餐记录缓慢调整，并非固定人格设定。

已验证的主人可以按页继续浏览已保存的旧日记，包括从模型活跃记忆中淡出或搁置的条目；标记删除的条目不在日记本中展示。翻看归档不会延长记忆有效期或改变原始内容。

旅行回来后，如果有人在外出期间以已验证身份放入食物，可以由模型决定是否感谢；只可能发给仍在私聊白名单且当前允许联系的对象，失败或结果不明不会自动重复发送。

`npm run release` 从白名单导出，并扫描账号和凭据模式，禁止包含运行状态、日志、备份、模型和登录目录。发布前仍需检查扫描结果及素材授权。
