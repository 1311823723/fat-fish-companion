# AI 与绘图接入

游戏核心不保存模型平台的账号密码。QQ 桥接负责调用已配置的 DSH 文本模型；核心的内部接口仅对本机桥接开放。意愿模型返回无效内容或不可用时留家，不随机决定地点。

## 当前绘图适配

适配社区插件 [LinLing4285/dsh-doubao-image-free](https://github.com/LinLing4285/dsh-doubao-image-free)，使用其本机 HTTP 接口，默认选择 GPT 的图生图。它依赖平台网页私有接口，平台变化时可能失败；服务未返回图片时明确失败，不创建相册条目。重试最多三次，失败不妨碍角色回家或 QQ 正常聊天。

按插件当前文档，可在实际 DSH profile 安装：

```powershell
dsh plugin --profile web add dsh-doubao-image-free
```

桌面 DSH 使用对应的 `desktop` profile，CLI 路径依安装位置而定。完整重启 DSH 后，在插件设置中亲自完成 GPT 或豆包登录。不要将 Token、Cookie、浏览器配置目录提交仓库。安装或登录操作由部署者决定，不自动读取其他软件的账号。

在本机 `config.local.json` 的 `drawing` 设置 `enabled:true`、实际 `baseUrl`、`provider:"gpt"` 和 `referenceFile`。固定参考图必须存在；不允许丢失参考图后改成无参考生成。仓库提供从角色授权图集提取的 `public/assets/reference-v1.png`，也可使用自己有权使用的固定参考图。本机既有角色参考图不会被自动替换。

设置 `provider:"doubao"` 可单独测试豆包；默认不会在两种风格之间静默切换。图片服务未返回图片不一定代表额度不足，需根据服务实际错误排查。

## 场景一致性

在旅途拍照事件时冻结时间、天气、动机、活动、动作、道具及参考版本。照片生成延迟或重试不会改场景。晴雨与夜景、吃饭与收起便当、撑伞与避雨分别有约束；生成式服务仍可能偏离构图或服饰细节，应检查实际样本。

网页只读取已完成照片及缩略图；原图按需打开。QQ 文案与日记上下文使用相同场景事件。分享经过现有白名单、忙碌保护和持久化发送预留，结果不明不自动重发。

### GPT 免费额度与结果识别

小屋会保存图片生成失败的安全摘要。识别到 GPT 生图额度耗尽后，按上游返回的重置时间加五分钟缓冲，暂停所有图片任务；聊天、回家和分享已有图片继续工作。重启后仍保留等待时间，相册会显示预计补试时间。时间仅是上游估计，恢复时仍可能受限。

如果使用 `dsh-doubao-image-free` 0.2.3，旧版可能将分段响应中的限额提示误报成“未解析到图片”。在插件目录备份后运行：

```powershell
node scripts/patch-image-plugin.mjs "你的插件目录"
```

补丁只补充最终会话结果和限额识别，不修改登录、校验或账号权限；修改后等会话空闲再重启 DSH。补丁会核对包名和源码锚点，不兼容版本会停止。不要把登录目录、凭据或补丁备份上传到 GitHub。此补丁无法增加账号额度。
