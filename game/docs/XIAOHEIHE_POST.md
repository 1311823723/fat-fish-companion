# 小黑盒介绍与教程草稿

建议标题：把大肥鱼养进网页小屋：能吃饭、旅行，还能陪你下四子棋（附自部署教程）

发布前补充自己的仓库链接和截图。以下是介绍草稿，不是已发布的帖子；不要在截图里露出 QQ 号、登录页、聊天、私人日记或配置。

## 正文

我想做的不是只在聊天框里回复的机器人，而是一间能用手机打开的小屋。网页里住着的大肥鱼，和 QQ 里陪你聊天的她，读取同一份生活状态：在家还是出门、吃了什么、带了什么、有没有回来，不再各说各的。

目前小屋里可以拉窗帘、开关灯、打开冰箱、补充食物、看旅行相册。主人验证后能翻固定纸页的日记本。她可以自己决定是否出游，留下便条，回来保存照片与纪念品；QQ 分享仍受部署者自己的白名单控制。

这次又挂上了一台小电视，可以跟她玩猜拳和四子棋。默认普通局，也有认真局。多人能同时各玩各的，想公开的玩家可以打开观战，别人只看不动。猜拳会先锁定她的出拳，再轮到玩家；四子棋本地计算，不用每落一步都等大模型。连接聊天模型后，结束时可以让她复盘。

这还是持续迭代的小项目，有生成图片细节偏差、网络和平台额度等实际限制，不是商业成品，也不是 DeepSeek 官方项目。角色原画与动画来自社区作者，素材的非商业授权需要一并保留。

## 最小部署：先不接 QQ 与模型

1. 安装 Node.js 24 和 Git，下载本仓库。不会 Git 的朋友可以在 GitHub 下载 ZIP 后解压。
2. 打开项目中的 `game` 文件夹，在这里打开终端。
3. 按顺序运行：

```powershell
npm ci
npm run setup
npm run build
npm run core
```

4. 浏览器打开 `http://127.0.0.1:3103/room`，选“访客进入”，点墙上的电视或工具栏“电视”。猜拳、四子棋和基础生活互动不需要大模型、绘图额度或显卡推理。
5. 想让手机访问、接 QQ、启用自主旅行和生成照片，再看仓库内的 `game/docs/DEPLOYMENT.md`、`BRIDGE.md` 与 `AI.md`。聊天模型、QQ 网关和绘图服务是分别接入的，不是打开这个网页就自动拥有。

常用命令：`npm test` 检查规则；`npm run doctor` 检查安装；`npm run backup` 备份数据库和旅行照片。升级前先备份，保存好自己的 `config.local.json` 和 `state`，不要用别人的存档覆盖。

## QQ 与记忆

进入网页不用交出口令。访客也能玩，关联原 QQ 记忆时，需要向机器人完成一次验证码验证，不能只填别人的 QQ 号就读取资料。已验证的人用 QQ 作为稳定身份，不受群昵称变化影响。自己的对局会记入个人经历，未验证访客不会获得其他人的信息。

## 私网、公网与部署助手

只在电脑自己玩，可以一直使用本地地址。要给家里手机或朋友访问，请按部署文档配置公开网关和可信来源。公网可选择固定隧道，也可以在其前面加 Cloudflare Pages 静态页面；Pages 不能代替仍需运行的本机后台。不要把 DSH、QQ 管理控制台、模型代理或内部接口直接公开。

仓库带有 `game/DEPLOYMENT_AGENT.md`。可以把仓库地址交给 DSH 等编程助手，让它先读这份文件，再按自己的电脑情况检查、部署。登录、扫码和平台授权请自己完成，不把密钥贴到帖子或聊天中。
