# 精细房间与机器可读布局

当前房间采用 `room-v5.webp` 插画、独立冰箱门与窗帘材质，角色仍使用原版授权动画。环境素材按版本保留；保留旧版素材作为回退资源。环境图由内置 Image Gen 生成，公开版本不依赖登录目录或本机生成记录。

生成提示词：

- 房间：完整竖屏 3:4 二维温暖手绘生活游戏室内；严格保留单人床、床头灯、中央拱窗与时钟、右侧冰箱、前景书桌日记与相册、地毯和留白的布局；象牙白亚麻、鼠尾草绿、蜂蜜色木材；丰富木纹、织物、缝线、体积与接触阴影；中性室内光；无人物、无文字、无界面。冰箱门单独制作，内部四层空架由程序按库存摆放食物。
- 冰箱门：参考房间中的同一复古绿色冰箱，正面、窄长圆角、奶油色把手、冷冻室分缝、小叶形磁贴；只输出完整门板，透明背景，无柜体、腿、食品与文字。
- 窗帘：两幅闭合象牙白亚麻窗帘的正面材质，柔软竖褶、中缝、底部小植物刺绣、中性光，无房间与文字。程序裁切到窗格内，日夜照明继续生效。

`public/assets/room-layout-v5.json` 是家具位置、操作、可站立点与行走路线的共同来源。网页使用它建立点击区域，QQ 的世界状态也带有同一份布局；不靠截图猜位置。更换插画时应同步校准这个文件。窗外天气与北京时间时钟由程序绘制，不烘焙到生活状态里。v5 增加可点击的旅行背包，角色出游时背包不在房间显示；旧版布局文件保留以兼容缓存。

日记本在客户端按固定 4:5 比例展示，正文依可用纸面分页。每篇内容按需读取，访客不会请求私人日记。桌面和手机翻页都保持同一设备下的尺寸，改变窗口大小后会重新排版，不改变原文或后端日记文件。

## 雾蓝鲸鱼房间（v3）

当前环境为雾蓝、奶白与浅木色，保留机器可读布局和原始角色。房间加入鲸鱼抱枕、尾鳍与波纹织纹、奶茶随行杯和旅行明信片。新增三张环境图由内置 Image Gen 生成；不包含角色、账号或私人旅行照片。

本轮生成要求：以原房间为布局参考，保持窗户、单人床、灯、冰箱、桌面日记与相册的坐标；改为柔和中性的雾蓝、奶白和浅灰木色，细化织物、木纹和接触阴影；鲸鱼主题只作为少量装饰，不添加文字与界面。独立冰箱门与窗帘材质使用相同色系。输出为 `room-v3.webp`、`fridge-door-v3.webp` 与 `curtain-v3.webp`，去除嵌入元数据。

窗帘两侧连续收拢，冰箱门围绕右侧铰链转动，正常开合约 650 毫秒。再次点击可从当前位置反向，开门时逐渐露出内部照明。天气仅在窗格内绘制，室内暗度随窗帘变化；尊重系统减少动态效果偏好。动画期间不重建库存图标，角色外出时仍可操作家具。

电脑端日记正文为 26px、行高 40px，手机端保留 17px、行高 28px；纸面保持固定比例并重新分页，不修改原文。
## 温馨色彩修订（v4）

在 v3 布局上通过内置 Image Gen 编辑，仅调整材质与色彩：暖奶油墙面、浅蜂蜜橡木、蓬松象牙白床品，保留雾蓝鲸鱼抱枕、针织毯和冰箱作点缀。保留所有家具、窗格和空冰箱的坐标与轮廓，不添加人物、文字或固定灯光。窗外、灯光和开合动画继续由程序控制。生成后的生产底图保存为 `public/assets/room-v4.webp`，其余 v3 分层素材继续复用。网页底色和面板同时使用暖纸色。保留前版文件以便回退，未改动角色和玩法。
## 房间布局修订（v5）

采用暖奶油墙面、浅蜂蜜木色与鲸鱼蓝，补出左侧墙面、墙角、踢脚线和透视地板。床位于左侧靠墙，书桌、日记和相册移至右下方，冰箱留在右后方，中间地毯与通路留空。通过内置 Image Gen 以 v4 为视觉参考生成独立底图 `room-v5.webp`；复用分层冰箱门和窗帘，角色保持原版。

生成要求：完整竖屏 3:4 手绘陪伴游戏卧室；显示浅侧墙和后墙的关系，家具落地、柔软接触阴影，保持温暖材质与鲸鱼装饰；单人床左侧、冰箱右后方且正面空架、书桌右下方（蓝色日记本、奶油相册、奶茶杯），中央留出活动地毯；无人物、文字和界面。窗格保留用于程序天气，床头灯不烘焙固定发光。新布局与所有点击区域、食物格、时钟、便条和角色站位一起校准。

`room-layout-v3.json` 的 `storybook-v3` 同时提供给游戏和 QQ。日记、相册、冰箱点击区跟随新位置；床上睡觉、桌前吃饭、地毯活动使用各自站位。旧版布局与图片保留作回退，不修改库存、日记、照片或记忆数据。
## 小游戏电视

新增独立透明素材 `public/assets/television-v1.webp`（512×267）。通过内置 Image Gen 生成：正面壁挂小电视，浅蜂蜜木框、鲸鱼蓝内边框、深蓝空屏幕、底部小尾鳍雕纹；无脚架、天线、文字或背景，沿用温馨手绘材质。程序绘制屏幕提示和小游戏界面。挂墙坐标、点击区与看电视站位保存在共享布局中，没有改动其他家具。

小游戏界面参考图采用暖纸、蜂蜜木边框、鲸鱼蓝棋盘、珊瑚色玩家棋子；文字、控件、胜负与状态由网页实现。手机保留七列六行的完整棋盘，列号按钮与棋盘均可落子，打开界面不会把弹窗点击透传给家具。

## 按选定概念图还原电视界面

采用独立透明木框、天线与空白标题牌素材 `tv-shell-v1.webp`，以及可复用的奶油/鲸鱼蓝按钮、棋子、空格、开关、关闭标记、气泡、徽标、箭头和猜拳手势。均通过内置 Image Gen 逐项生成，公开产物只包含压缩后的无元数据 WebP，不包含源截图、账号或生成记录。

提示词约束：保持参考图中的蜂蜜木框、圆头天线、小脚、纸色内屏、深蓝重字；按钮有柔和高光和压下反馈；珊瑚色与鲸鱼蓝棋子带手绘光泽；空格为浅奶油色凹孔，使用薄蓝灰内沿，不做金色凸起硬币；猜拳手势是奶油色手绘手掌和蓝色描边。所有承载游戏文本的素材保持空白，文字、数字与胜负由网页呈现。

手机按竖屏电视比例排版，列号、棋盘和按钮是真实可操作控件；背景保留当前小屋，不用概念图替代真实房间。公开教程插图使用隔离的演示存档，不含真实账号、聊天或私人日记。

电视上线使用 room-layout-v4.json / storybook-v4 作为新缓存版本，避免老访客缓存的布局缺少电视；历史布局文件继续保留。
