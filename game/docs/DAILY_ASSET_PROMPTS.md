# 每日生活素材制作

使用内置 imagegen，无需部署者运行生图。运行时只加载仓库中的已整理 WebP。生成参考：房间 room-v5.webp 的温暖手绘色调；角色动作为 reference-v1.png。原始生成图不随发布包复制。

## 食物图集提示词

透明背景、严格 4×4 等格、16 个独立居中食物图标。温暖绘本水粉，奶油白与浅蓝陶瓷，略俯视的三分之四角度，留透明边距，无文字、编号、网格、人物和背景装饰。按行依次为：番茄炒蛋、可乐鸡翅、小酥肉、紫菜蛋花汤；奶茶、柠檬水、蛋包饭、咖喱鸡饭；番茄牛肉面、鲜肉小笼包、扬州炒饭、海苔饭团；玉米浓汤、热可可、橙汁、草莓酸奶。各格完整且不能互相越界。

## 随身小物图集提示词

透明背景、严格 3×3 等格、九件独立随身小物。使用房间参考的奶油白、鲸鱼蓝与蜂蜜木色，手绘织物与陶瓷质感，无文字或背景。按行依次为：小相机、折叠雨伞、小地图；折叠毯子、小水壶、随手本；望远镜、小手电、鲸鱼挂件。小物完整，四周留透明边距。

## 翻书动作提示词

仅使用角色参考图作为身份依据，保持蓝发、呆毛、头饰、眼形、鳍饰、蝴蝶结、白围裙与鲸鱼图案、蓝裙和尾巴，不换装、不改人物。透明背景 4×2 等格八帧，所有帧同一尺度、方向、位置与脚底基线。角色坐在看不见的座位上，双膝并拢，在膝前拿打开的小蓝本；只让眼皮、头部、手和书页轻微变化：看书、眨眼、继续看、伸手到页边、翻一页、纸页落下、小幅歪头、回到初始阅读姿势。无文字、桌椅、食物和其他角色。继承原游戏角色画风。

## 后处理

`scripts/prepare-daily-assets.mjs` 接受三份原始图集路径，保留每格最大相连轮廓，去离散透明噪点，生成小尺寸库存图标与冰箱图集。翻书各帧使用一致缩放与 y=244 基线，重排成首尾一致的 12 帧循环，256×256、3 fps，按需加载。

`scripts/export-reading-contribution.mjs` 可导出逐帧 PNG、GIF 预览、时序、哈希与贡献说明。角色动作按 CC BY-NC-SA 4.0，环境小图标按 MIT；不得将新动作描述为原作者制作或已审核。
